# Week 5 – PySpark DataFrames

##  Objective

The objective of this assignment is to understand Apache Spark fundamentals and perform data cleaning, filtering, transformation, aggregation, and schema modification using PySpark DataFrames. It also demonstrates how Spark processes large datasets efficiently using in-memory computation.

---

##  Topics Covered

- Spark vs. MapReduce
- In-Memory Computing
- Spark DataFrames
- Data Cleaning
- Removing Duplicate Records
- Handling Missing Values
- Data Filtering
- Aggregation Functions
- GroupBy Operations
- Wide Transformations (Shuffle)
- Schema Modification
- Complete Data Processing Pipeline

---

##  Tools & Technologies

- Python
- Apache Spark (PySpark)
- Google Colab

##  Learning Outcomes

By completing this assignment, I learned to:

- Work with Spark DataFrames for large-scale data processing.
- Perform data cleaning by handling duplicates and missing values.
- Apply filtering and transformation operations.
- Use aggregation functions such as `count()`, `sum()`, `avg()`, `min()`, and `max()`.
- Group data using `groupBy()` and apply aggregate functions.
- Modify DataFrame schemas through casting and renaming columns.
- Understand shuffle operations and wide transformations.
- Build an end-to-end data processing pipeline using PySpark.
