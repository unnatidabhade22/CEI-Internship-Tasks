# Week 6 – Spark Architecture and Optimized Data Processing

## Objective

The objective of this assignment is to understand the architecture of Apache Spark and perform efficient data processing using PySpark DataFrames. The practical covers Spark execution concepts, DataFrame transformations, filtering, schema handling, optimized storage formats, and building a complete data processing pipeline.

---

## Topics Covered

- Apache Spark Architecture
- Driver, Cluster Manager, and Executors
- Client Mode vs Cluster Mode
- Lazy Evaluation
- Directed Acyclic Graph (DAG)
- Fault Tolerance
- Reading CSV and Parquet Files
- DataFrame Transformations
- Filtering and Selecting Data
- Column Renaming and Data Type Casting
- Handling Null Values
- Adding New Columns
- Aggregation Operations
- Predicate Pushdown
- CSV vs Parquet Performance
- Spark Best Practices
